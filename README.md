# Segmented Style Transfer

This project implements a region-aware style transfer system by combining Segment Anything Model (SAM) with Adaptive Instance Normalization (AdaIN). It allows you to apply different artistic styles to specific objects or regions in a single image.

This project implements region aware style transfer by combining Segment Anything Model (SAM) with Adaptive Instance Normalization (Ada(N) based on the paper [Arbitrary Style Transfer in Real-time with Adaptive Instance Normalization](https://arxiv.org/abs/1703.06868)
